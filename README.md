# The Funniest Out-of-Office

Entry for the [make.fun](https://make.fun) bounty "The Funniest Out-of-Office" — one line of out-of-office auto-reply text, 140 characters or fewer.

## The entry

> I'm out of office until Monday. I'm actually at my desk — this reply is my alibi, so please play along.

Run `python3 main.py` to write the line to `/output/entry.txt` (override the directory with the `OUTPUT_DIR` environment variable). Standard library only, no dependencies.
